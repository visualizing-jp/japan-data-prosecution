# データソース

「日本では捕まえた人をどれだけ起訴してきたか」探索ダッシュボードのための、データソース調査とデータ層の設計方針。
実装前の意思決定記録。調査日: 2026-09-11。軸は e-Stat 年報 Excel と犯罪白書 Excel の実測値で確認済み。

## 1. 結論

検察庁が受け取った事件の**起訴・不起訴・起訴猶予**を、**時代・罪名・地検管内**の3ビューで見せる。
一次ソースは法務省「検察統計調査」（政府統計コード `00250003`）年報の**累年比較表**。
処理区分の定義と見やすい長期系列は、法務省「令和7年版 犯罪白書」第2編第2章第4節の Excel を併用する。

警察庁犯罪統計の API 単年表と同じ罠がある。e-Stat データベース表は年次プレフィックス（`24-00-xx`）の単年が中心で、長期比較には向かない。第1版は年報の累年表と白書 Excel を採用する。社会・人口統計体系（SSDS）は使わない。

| ビュー | 一次ソース | 表 | 次元 | 指標 |
| --- | --- | --- | --- | --- |
| 時代 | 犯罪白書 Excel + 年報累年 | `2-2-4-1` / `2-2-4-2` + `24-00-02` | 指標×年 | 終局処理・起訴率・起訴猶予率・処理区分 |
| 罪名 | 検察統計年報 | `24-00-05`（受理は `24-00-03`） | 罪名×年 | 起訴・不起訴・起訴率 |
| 地域 | 検察統計年報（単年） | `24-00-12` + `24-00-11` | 地検管内×罪名 | 人口10万人当たり受理、起訴・起訴猶予 |

出典表記: 法務省「検察統計」（e-Stat）。処理区分の長期は同「犯罪白書」。

`crime`（認知・検挙）の姉妹。裁判の有罪・量刑は最高裁司法統計で、第1版の対象外。

## 2. 採用データセット（メタ・実測）

### 犯罪白書 `2-2-4-1.xlsx` — 終局処理人員の処理区分（1989–2024）

- 出典: [令和7年版 犯罪白書 第2編第2章第4節](https://hakusyo1.moj.go.jp/jp/72/nfm/n72_2_2_2_4_0.html) の Excel
- 注記どおり原統計は検察統計年報
- 軸: 年 × 処理区分（公判請求 / 略式命令請求 / 起訴猶予 / その他の不起訴 / 家庭裁判所送致）
- 実測（2024年 / 令和6年）:
  - 終局処理人員総数 **782,735**
  - 公判請求 80,287（構成比 10.3%）
  - 略式命令請求 158,783（20.3%）
  - 起訴猶予 429,432（54.9%）
  - その他の不起訴 64,586（8.3%）
  - 家庭裁判所送致 49,647（6.3%）
  - 起訴率 **32.6%**（起訴 239,070 / (起訴+不起訴)）
  - 公判請求率 11.0%（図②。分母は家裁送致を含まない起訴・不起訴側。図①の構成比 10.3% とは分母が違う）
- 1989年の終局処理は 2,221,317。長期の減少が時代ビューの主線

### 犯罪白書 `2-2-4-2.xlsx` — 刑法犯と特別法犯の起訴率（1982–2024）

- 道交違反を除く特別法犯と刑法犯を分けた起訴・不起訴・起訴猶予率
- 実測（刑法犯、2024年）: 起訴 69,026 / 不起訴 113,926 / 起訴率 37.7% / 起訴猶予率 52.3%
- 実測（刑法犯、1982年）: 起訴率 57.5%。起訴率の低下が罪名ビューと接続する
- `2-2-4-4.xlsx`（起訴猶予率の図）はタイトルのみで数値表が空。起訴猶予率は本表と `2-2-4-1` から算出する

### 検察統計年報 `24-00-02` — 受理・既済・未済人員の累年比較（大正7年–令和6年）

- e-Stat `statInfId=000040302370`（2024年年報、公開 2025-08-29）
- タイトル: 被疑事件の受理、既済及び未済人員の累年比較
- 人員の長期はここが最長。大正6年以前は人員調査なし（表注7）
- 昭和20年は戦災で欠測（表注3）
- 実測:
  - 大正7年（1918）受理総数 478,588 / 起訴 174,568
  - **昭和40年（1965）受理総数 8,225,842 / 起訴 4,624,606**（系列のピーク）
  - 昭和43→44年に受理が 6,041,359 → 3,929,209。交通反則通告制度（昭和43年）による構造変化
  - 令和6年（2024）受理総数 927,108 / 既済 898,754 / 起訴 239,070
- 既済の起訴 239,070 は白書の起訴（公判+略式）と一致する
- 終局処理人員（白書）は既済から中止・他庁移送を除き、起訴+不起訴+家裁送致。2024年は 782,735 で既済 898,754 より小さい

### 検察統計年報 `24-00-05` — 罪名別起訴・不起訴・起訴率（平成23年–令和6年）

- e-Stat `statInfId=000040302373`
- 実測（総数、2024年）: 起訴 239,070 / 不起訴 494,018 / 起訴率 **32.6%**（白書と一致）
- 実測（総数、2011年）: 起訴 474,125 / 不起訴 880,287 / 起訴率 35.0%
- 罪名分類は付録「罪名分類一覧表（その1）」の大分類。第1版は主要罪名に絞る

### 検察統計年報 `24-00-03` — 罪名別通常受理人員（平成21年–令和6年、**2010年以降を採用**）

- e-Stat `statInfId=000040302371`
- 平成21年（2009）の「道路交通法等違反」が **0**。平成22年は 453,349。総数も 429,160 → 1,568,299 と切断している
- 第1版の罪名×年の受理は **2010–2024** に限る
- 実測（総数、2024年）: 通常受理 778,287

### 検察統計年報 `24-00-12` — 地検管内別 人口10万人当たり通常受理（2024年単年）

- e-Stat `statInfId=000040302400`
- 人口は令和3年国勢調査基準の推計人口（令和6年10月1日現在）
- 実測（全国）: 刑法犯 392.3 / 傷害 18.7 / 殺人 1.1 / 不同意性交等 3.0（人口10万人当たり）
- 地検管内は都道府県に近いが一致しない（横浜・さいたま等）。地図は地検管内ラベルで出す

### 検察統計年報 `24-00-11` — 地検管内別 通常受理・起訴・起訴猶予・家裁送致（2024年単年）

- e-Stat `statInfId=000040302399`
- 自動車による過失致死傷等および道路交通法等違反を**除く**
- 実測（総数）: 通常受理 292,519 / 起訴 105,817 / 起訴猶予 106,499 / 家裁送致 31,543
- 地域の起訴率はこの表から算出する（道交を除いた比較になる）

## 3. 見送り（第1版）

| 候補 | 理由 |
| --- | --- |
| e-Stat API の年次単表 | 表番号が `24-00-xx` の単年。長期に不足。crime と同じ判断 |
| SSDS「Ｋ　安全」 | 認知・検挙は `crime` の領域。起訴率の長期は年報累年の方が厚い |
| `24-00-01` 件数の明治系列（明治15年–昭和25年） | 件数であり人員と接続できない。大正6年以前は人員調査なし |
| `24-00-04` 少年の罪名別受理 | 対象は `juvenile`。crime の少年検挙とも段が違う |
| 外国人被疑事件（`24-00-13` 以降） | 物語の核ではない。第2版 |
| 勾留・処理期間（`24-00-30` 以降） | 手続の細部。第1版の3ビューに不要 |
| 確定裁判・刑の執行（`24-00-63` 以降） | 裁判所側。司法統計の領域に近い |
| 白書 `2-2-4-4.xlsx` | 数値表が空。`2-2-4-2` で代替 |
| 白書 CD-ROM 資料 2-2（罪名別終局処理） | 第1版は年報 `24-00-05` で足りる |

## 4. 接続・定義ルール

犯罪白書凡例に合わせる。

- **起訴率** = 起訴人員 / (起訴人員 + 不起訴人員) × 100
- **起訴猶予率** = 起訴猶予人員 / (起訴人員 + 起訴猶予人員) × 100
- **終局処理人員** = 起訴 + 不起訴 + 家庭裁判所送致。中止・他の検察庁への移送は含めない
- **起訴** = 公判請求 + 略式命令請求
- 総数は過失運転致死傷等および道交違反を含む。道交の略式が総数の起訴率を押し上げるため、時代ビューは**総数と刑法犯を併記**する
- 表示年は西暦。和暦はツールチップ可
- 地域の相対色は全国（人口10万人当たり）比
- 昭和20年は欠測。昭和43年の交通反則通告は注記する

## 5. 配信ファイル

`scripts/build_data.py` → `public/data/`（crime と同じ cube）

| ファイル | 次元 | 指標 | 辞書 |
| --- | --- | --- | --- |
| `era.json` | metric × year | persons / rate | metrics |
| `type.json` | code × year | indicted / nolle / rate | codes |
| `geo.json` | metric × year × area | value / relative | metrics, areas |

cube 形式は `dims` + `measures`（行優先）+ 辞書。欠測は `null`。
地域は第1版単年でも `year` 次元を持たせ、翌年の年報で延長できるようにする。

## 6. 注記（UIに短く出す）

- 警察が検挙しても、微罪処分と交通反則は検察に来ない
- 総数の大半は交通関係と起訴猶予である。刑法犯だけを見ないと「日本は起訴しない」の印象が歪む
- 受理人員のピークは1965年前後。1968年の交通反則通告で系列が折れる
- 地検管内は都道府県そのものではない
- 起訴率の分母に家裁送致は入らない

## 7. 更新手順

API キーは不要（第1版はファイルダウンロード）。

1. `npm run fetch` で年報・白書の Excel を `data/raw/` に置く（[e-Stat 検察統計年報](https://www.e-stat.go.jp/stat-search/files?toukei=00250003) の最新年次。2024年は `lid=000001463686`）
2. [犯罪白書](https://hakusyo1.moj.go.jp/jp/nendo_nfm.html) の URL は `scripts/fetch-xlsx.sh` が年版パスを持っている。新年版では差し替える
3. `npm run data && npm run verify`
4. 白書の終局処理・起訴率が年報の起訴・不起訴と一致することを確認する
5. `24-00-03` の道路交通法違反が年次によって 0 になっていないか確認する

`ESTAT_APP_ID` は第2版で API を使うときまで不要。配信用 JSON は追跡する。
